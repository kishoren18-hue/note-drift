# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Use GitHub's private reporting instead:
go to the **Security** tab of this repository and choose **Report a vulnerability**.

You can expect an acknowledgement within a few days. Once a fix is ready, it will be released and
the report credited unless you prefer otherwise.

## Safety issues

This tool handles medical information. If you find an input that makes it report something wrong
with confidence (for example, scheduling a medicine at the wrong time, or missing a changed dose),
please treat it like a security issue: report it privately with a synthetic example, not real
patient data. These reports get the highest priority.

## Supported versions

Only the latest release receives fixes.
