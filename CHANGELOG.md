# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-11-04

### Added

- About 70 brand-to-generic name mappings (Tylenol matches acetaminophen)
- Custom vocabularies via `--lexicon` JSON or the `Vocabulary` API
- `note-drift batch` for whole folders with CSV output and per-pair HTML reports
- Contributor docs, issue templates, linting and coverage in CI, release workflow

## [0.1.0] - 2026-11-04

### Added

- Extraction of allergies, medications, vitals, labs, negated conditions and laterality
- Severity-ranked comparison, side-by-side HTML report, synthetic error-injection benchmark
